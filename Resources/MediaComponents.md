# Media components

The app bundles these separate command-line tools. It does not download code, load user yt-dlp configuration/plugins, or update itself at runtime. Browser cookies are not read by default; users can explicitly enable browser authentication for supported site downloads in Settings. The CLI stays anonymous. yt-dlp reads the selected profile cookie jar and may create temporary database copies; Folioak does not export a cookies file or store Cookie contents in preferences, history or logs. Component updates ship with an application update after validation. Build inputs and SHA-256 hashes are pinned in `Tools/prepare-media.py`.

- yt-dlp 2026.08.19: https://github.com/yt-dlp/yt-dlp/releases/tag/2026.08.19 — upstream source is Unlicense; the official macOS PyInstaller directory distribution includes GPLv3+ components. All Python modules and extractors are retained; Mach-O binaries contain only arm64, and duplicate framework files use the standard relative symlinks. See the included third-party license file and https://github.com/yt-dlp/yt-dlp/blob/2026.08.19/README.md#licensing. EJS is included in this distribution.
- QuickJS-NG 0.17.0: https://github.com/quickjs-ng/quickjs/releases/tag/v0.17.0 — MIT. The unmodified engine is built for macOS 13 with `Tools/QuickJSHost.c`, a minimal host for yt-dlp's EJS solver. JavaScript has console output but no file, network, process or module-loading APIs; memory and execution time are bounded. No JIT or library-validation entitlement is needed.
- FFmpeg / ffprobe 8.0.1: https://ffmpeg.org/releases/ffmpeg-8.0.1.tar.xz — built from unmodified source, LGPL configuration, with private shared libraries beside the executables, without GPL/nonfree/external libraries or networking. The exact configure invocation is in `Tools/prepare-media.py`; copyright/license texts are included. Source and build instructions allow rebuilding these independent executables.

The FFmpeg build keeps the existing demuxers, decoders, parsers and bitstream filters for input compatibility. Output encoders are limited to AAC for M4A extraction; video merging and repairs copy the original streams. Output containers cover MP4/MOV/M4A, Matroska/WebM, ADTS, MP3, WAV, FLAC, Ogg/Opus and MPEG-TS. Only FFmpeg's required basic filters and audio resampling are retained. Both tools share the bundled libraries through `@loader_path`, without Homebrew or system FFmpeg dependencies. Every executable and library is architecture-checked, signed and included in the cache hash manifest.

Local Mach-O symbols are stripped from Python libraries; exported symbols remain. `Tools/repack_python.py` stores the original PYZ module bytecode in standard zlib level-0 streams, allowing the outer DMG LZMA compressor to share its dictionary across modules. Every module's decompressed bytes are checked for equality before the executable is re-signed. No module, extractor or runtime dependency is removed.

Media routing accepts individual YouTube, Bilibili, X, standard Toutiao, Xiaohongshu, Douyin, TikTok, Instagram and Vimeo video URLs. Recognized Xiaohongshu/TikTok short links pass through the bundled extractor's redirect handling. Douyin single videos use a native anonymous resolver against the official mobile `slidesinfo` endpoint, including validated short-link redirects. It reads no browser cookies even when browser authentication is enabled. Only validated metadata fields and public HTTPS playback URLs enter a private temporary info JSON for yt-dlp; the JSON is removed after the downloader exits. Video transfer, quality selection, M4A extraction and final file validation remain shared. Image posts are excluded; unavailable or malformed metadata is reported without assuming login is required. Xiaohongshu access parameters are preserved. Each platform's aliases share a cooldown group. Profiles and collections are excluded at input; a recognized URL does not guarantee download availability. Sites may require authentication or verification even for public content; the app can use explicitly enabled browser authentication, while anonymous downloading remains the default. Direct HTTPS image/audio/video links use the native transport. Partial yt-dlp transfers are kept in the app's `MediaDownloads` support directory for retry; successful output is validated before publication. The default output uses an available video+audio combination; audio extraction saves M4A. PDFs retain the existing paper workflow.

The in-app About panel shows component versions from the prepared media manifest and the bundled CPython framework, with upstream links and access to the included licenses. Douyin endpoint discovery references [parse-video-py at `dab1270`](https://github.com/wujunwei928/parse-video-py/blob/dab12708368eae054ba2dae5db16d8b040b9029e/src/parse_video_py/parser/douyin.py) (MIT); it is an implementation reference, not a bundled backend.
