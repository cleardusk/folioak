# arXiv 下载器

简洁的原生 macOS 论文下载工具。默认保存到 `~/Desktop/PhD/PapersRepo`，记住上次选择的目录。

## 安装

从私有仓库的 [Releases](https://github.com/cleardusk/arxiv-download-ui/releases) 下载 DMG 安装包，打开后将应用拖入 Applications。支持 Apple Silicon，最低 macOS 13；需要登录有仓库访问权限的 GitHub 账号。也可下载 ZIP 解压安装。当前未做 Apple 公证，首次打开可能需要在系统「隐私与安全性」中允许打开。

## 使用

双击 `dist/arXiv 下载器.app`，粘贴一个或多个 arXiv 链接，点击「开始下载」。每行一个，也可以用空格、逗号或分号分隔。支持摘要页、PDF、HTML 链接，以及 `2609.22978` / `arXiv:2609.22978` 这样的编号，包括旧式编号。

- 无版本号：获取当前版本的元数据，然后下载该明确版本。
- 带 `v1` 等版本号：下载对应版本。
- 默认命名：`[arXiv2026.9][论文标题].pdf`；年月取首次提交日期。设置中也可选「编号 + 标题」或「仅标题」；冒号等字符改为短横线。设置变化不会重命名旧文件。
- 同批相同编号、相同版本的链接自动去重。无版本号和指定版本作为不同请求处理。
- 同名、相同内容：复用已有文件。不同内容：加 `[论文编号v版本]` 后缀；再次冲突加序号。不会覆盖现有文件。
- 完成项可直接打开；「…」菜单可查看文件信息、复制文件名、在 Finder 中显示或打开 arXiv 页面。文件不存在时可重新下载。
- 下载时可取消；失败项可单独或批量重试。无效输入的「修改」会选中对应输入项，修改后重新开始。
- `⌘ Return` 开始下载，`Esc` 取消；`⌘ ,` 或齿轮打开设置。
- 设置包含保存目录、三种文件命名及系统/浅色/深色外观，立即保存。主界面与设置共享同一个目录；下载中的批次固定目录和命名。

目录、命名、外观和主题跨启动保留，任务列表不保留。所有下载直接来自 arXiv，没有账号、后端服务或遥测。

设置中的「主题」提供原生、石墨、鸢尾、海湾、琥珀、午夜六套配色，点击预览即可应用。每套都有浅色与深色版本，可独立选择「跟随系统 / 浅色 / 深色」；背景、输入区与操作颜色一起变化，成功与错误颜色保留原语义。下载中也能切换主题，选择跨启动保留。

## 构建与测试

开发需要 Apple Command Line Tools 或 Xcode。应用面向 Apple Silicon，最低 macOS 13；运行已构建应用不需要开发工具或 Python/Node。

```sh
./build.command
./package.command
./test.command
./test.command --live
./test.command --stress
./test.command --snapshots
```

`--live` 在 `build/live-UUID/` 中下载并复核真实 DSec 论文，不写入 PapersRepo。
`--stress` 完成 200 次模拟下载队列，检查模型释放、内存峰值和临时文件清理。
`--snapshots` 在 `build/qa/` 输出六套主题的深浅色、较窄窗口、空输入、下载中／取消及长目录设置预览。

推送与应用版本一致的 `vX.Y.Z` tag 后，GitHub Actions 自动测试、打包并发布 Release。安装、构建与发布步骤见 [RELEASING.md](RELEASING.md)。

`Sources/App.swift` 包含界面、原生文本输入与队列状态；`Sources/Theme.swift` 包含主题色板与选择预览；`Sources/Core.swift` 包含 arXiv 元数据、网络请求和文件保存，便于后续加入其他来源或历史记录。测试位于 `Tests/`。

## 可靠性与边界

输入最多 64 KiB，每批最多 200 条；元数据最多 1 MiB，单个 PDF 最多 256 MiB。超过限制会明确报错。元数据只接受 UTF-8，拒绝 DTD 与外部实体；网络只允许三个官方 arXiv 域名的 HTTPS 请求和重定向，保留系统 TLS 校验。下载进度更新约每 100 ms 一次，防止频繁刷新界面。

网络请求串行处理、至少间隔 3.1 秒；超时、429、5xx 或损坏 PDF 最多尝试三次，遵守 `Retry-After`，冷却时间延续到下一篇。服务器要求等待超过一分钟时报告需等待的时间；当前进程内后续任务和手动重试也不能绕过等待。404 等永久错误不自动重试。

PDF 在临时位置下载，核验格式结束标记、PDFKit 可读性及页数后，复制到目标目录中的临时文件，通过排他重命名提交；原文件不被覆盖。正常取消会清理临时文件；下载中退出会先确认，再等待取消和清理完成。强制结束程序或系统断电可能留下 `.arxiv-UUID.partial` 临时文件，但不会把它标记为完成。

校验用于识别明显损坏或非 PDF 文件，不保证每页视觉内容都正确。内容哈希比较可能需要重新下载已有论文，iCloud 中的旧文件也可能需要先被系统取回。

文件哈希每次读取 1 MiB，拒绝管道、特殊文件、符号链接和超大文件。已有同名路径若不能安全比较，会使用冲突后缀另存，保留原路径。每批重建列表缓存，避免连续换批累积界面内存。

目标磁盘需要支持排他重命名；不支持时会报错，不退化为覆盖保存。已在本机 APFS 验证，外置磁盘与网络盘未逐一验证。

此版本使用 ad-hoc 签名并开启 Hardened Runtime；尚未使用 Developer ID 签名和 Apple 公证，也未启用 App Sandbox。向其他电脑分发时，系统可能要求额外的打开确认。PDF 由系统 PDFKit 解析；文件大小限制不能保证恶意 PDF 的解压或解析资源消耗有界，校验也不属于病毒扫描。

安全与资源实测见 `SECURITY-AUDIT.md`。请求会向 arXiv 发送论文编号；不上传本地文件、保存目录或剪贴板全文。

arXiv API 文档与请求限制：
- https://info.arxiv.org/help/api/user-manual.html
- https://info.arxiv.org/help/api/tou.html
